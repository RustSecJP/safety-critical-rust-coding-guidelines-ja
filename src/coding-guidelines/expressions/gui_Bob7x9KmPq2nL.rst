=========================================================

.. guideline:: 参考文献付きのガイドラインの例

   :release: 1.0.0-latest

   これは、参考文献の機能を示すためのガイドラインの例です。
   
   :cite:`gui_Bob7x9KmPq2nL:RUST-REF-UNION` に記載されているとおり、Rust の共用体型には特有の安全性の要件があります。
   CERT C コーディングスタンダード :cite:`gui_Bob7x9KmPq2nL:CERT-C-INT34` は、シフト演算で未定義動作を避けるための指針を示しており、
   これは Rust にも当てはまります。
